# Mini Project Proposal

## Project Title

Rule-Based NLP Chatbot

## Problem Statement

Many users need quick answers to common questions, but human support may not always be available. This project aims to develop a simple chatbot that can understand predefined user inputs and provide appropriate responses using rule-based Natural Language Processing (NLP).

## Dataset

The chatbot will use a custom dataset consisting of common user questions and predefined responses.

Example:

| User Input  | Response                               |
| ----------- | -------------------------------------- |
| hello       | Hi! How can I help you?                |
| what is ai  | AI stands for Artificial Intelligence. |
| how are you | I am doing well. Thank you!            |
| bye         | Goodbye! Have a nice day.              |

The dataset will be stored in a Python dictionary or CSV file.

## Algorithm / Technique

The project will use Rule-Based NLP.

Steps:

1. Take user input.
2. Convert text to lowercase.
3. Match the input with predefined keywords or patterns.
4. Return the corresponding response.
5. If no match is found, display a default message.

## Expected Output

The chatbot will:

* Respond to greetings.
* Answer basic AI-related questions.
* Handle simple conversational queries.
* Display a default response for unknown questions.

Example:

User: hello

Bot: Hi! How can I help you?

User: what is ai

Bot: AI stands for Artificial Intelligence.

## Tools and Technologies

* Python
* VS Code
* NLP Concepts (Token Matching)
* Dictionaries / CSV Files

## Expected Outcome

The project will demonstrate the basic working of a chatbot using NLP concepts and provide an interactive conversation experience through predefined rules.
